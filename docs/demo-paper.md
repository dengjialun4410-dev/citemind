# Attention-based Scientific Document Retrieval

## 摘要

本研究提出一种面向科研文献的混合检索方法。系统将关键词检索与向量语义检索结合，并使用重排序模型对候选段落重新打分。实验表明，混合检索能够改善专业术语和语义改写问题的召回效果。

## 方法

文档首先按照标题和段落结构切分，每个证据块保留文件名、章节路径和页码。查询阶段并行执行词项匹配与向量相似度搜索，再融合两路候选结果。生成模型只能使用检索到的证据回答问题，并需要为关键结论标注来源。

## 结论与局限

证据约束可以提高回答的可核查性，但系统仍依赖文档解析质量。对于扫描版 PDF、复杂数学公式和跨页表格，需要结合 OCR、版面分析和专用表格解析模型进一步处理。
